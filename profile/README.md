The Next Web Working Group develops focused proposals for the web platform, publishes the work in
the open, and moves proven ideas toward the standards bodies that can adopt them. It is an
independent group, not a W3C Working Group; see [nextwebwg.org](https://nextwebwg.org/).

| Proposal | Specification | Implementation |
| --- | --- | --- |
| Declarative HTML Components | [nextwebwg.org/html-next](https://nextwebwg.org/html-next/) · [source](https://github.com/nextwebwg/specs/tree/main/html-next) | [html-next](https://github.com/nextwebwg/html-next) |
| HTML Forms | [nextwebwg.org/html-forms](https://nextwebwg.org/html-forms/) · [source](https://github.com/nextwebwg/specs/tree/main/html-forms) | |

Anyone may participate. Read the [contribution terms](https://github.com/nextwebwg/.github/blob/main/CONTRIBUTING.md),
the [governance](https://github.com/nextwebwg/.github/blob/main/GOVERNANCE.md), and the
[code of conduct](https://github.com/nextwebwg/.github/blob/main/CODE_OF_CONDUCT.md).
