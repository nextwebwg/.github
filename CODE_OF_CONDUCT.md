# Code of Conduct

The Next Web Working Group adopts the
[W3C Code of Conduct](https://www.w3.org/policies/code-of-conduct/) for every space the group
runs: its repositories, issues, pull requests, discussions, and meetings.

Report a concern privately to a chair: [Matthew Dean](https://github.com/matthew-dean). The chairs
handle reports as the W3C Code of Conduct describes and keep them confidential.
